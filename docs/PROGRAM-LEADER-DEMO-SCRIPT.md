# Program Leader 功能介紹腳本（Demo Script）

- 角色：Program Leader（課程計畫負責人）
- 示範帳號：`sarah` / `Demo1234!`
- 預計時長：約 6–8 分鐘
- 格式：【畫面操作】＝你要點的地方；「台詞」＝你要講的話

---

## 0. 開場（約 30 秒）

「大家好，接下來我要介紹 Skill UP 裡的 **Program Leader** 角色。
Skill UP 有四種角色：Learner 學習、Instructor 開課，Admin 管帳號，而 Program Leader 位在中間，負責**管理學習計畫（Program）、把關課程品質、並掌握整體學習成效**。
Program Leader 的導覽列有五個入口：**Overview、Programs、Instructors、Course approvals、Messages**，另外還能進 Analytics 與 Learners。我們一個一個來看。」

【畫面操作】登入頁 → 輸入 `sarah` → 登入，自動進入 Dashboard。

---

## 1. Overview 總覽儀表板（約 1 分 30 秒）

【畫面操作】停在 Dashboard，由上而下指給觀眾看。

「登入後第一個看到的是 **Overview 儀表板**，一眼就能掌握自己負責的所有計畫。」

1. **頂部指標卡（Metrics）**：「這裡是關鍵數字，例如管理的課程數、學習者數、待審核數量。」
2. **Weekly Platform Activity 活動圖表**：「這張圖顯示平台活躍度，並與**前一個期間**比較。上方可以切換時間區間。」
   【點擊】切換 Period 按鈕，讓圖表更新。
3. **Course performance 課程表現**：「用下拉選單選一門課，就能看到課程詳情、完成率，以及 **Learner breakdown 學習者分佈**。」
   【點擊】下拉選單換課 → 點右上「⋯」選單，示範三個捷徑：**View course / Edit course / Program analytics**。
4. **Learning summary 學習摘要**：「整體學習狀況的摘要。」
5. **Alerts & notifications 提醒與通知**：「右側是通知中心，可以用篩選器分成 **Unread / Read / Archived**，點開每則通知可以直接執行動作，例如前往處理。最下方會顯示『有幾件待審核』，點進去就是審核頁。」
   【點擊】開啟篩選器，切換 Unread → Read。
6. **左側快速導覽列（Rail）**：「所有功能都能從這排圖示快速跳轉。」

---

## 2. Programs 計畫管理（約 2 分鐘）

【畫面操作】點選側邊欄 **Programs**。

「**Program 就是把多門課組成一條學習路徑**，學習者依順序完成。這裡就是 Program 的管理中心。」

### 2.1 計畫列表
- 「每個計畫以卡片呈現，上方有**搜尋框**可以用名稱搜尋。」
  【操作】在搜尋框輸入關鍵字。
- 「只會看到**指派給我的計畫**，別人的看不到，這是權限控管。」

### 2.2 建立計畫
【點擊】**+ New program**
- 「填入 **Program name、Description**，並用開關決定要不要 **Publish learning path**。發佈後，學習者才會在學習路徑上看到。」
- 【點擊】**Save program**（也可示範空白送出，顯示必填驗證）。

### 2.3 編輯 / 刪除計畫
- 「卡片選單可以 **Manage courses、Edit details、Delete program**。」
- 「注意：**只有沒有課程的計畫才能被刪除**，避免誤刪。」

### 2.4 管理學習路徑（重點）
【點擊】進入某個計畫。
- 左側摘要：「Program 狀態（Published / Draft）、已指派課程數、路徑中的課程數、報名人數。」
- **Learning path 區塊**：「這裡決定學習者看到的**課程順序**。用 **↑ ↓** 調整順序，**Remove** 從路徑移除，但課程仍屬於這個計畫。」
  【操作】按 ↓ 調整一門課 → 點 **Save path** 套用；再示範 **Discard path changes** 放棄修改。
- **Other courses in this program**：「尚未加入路徑的課程，可以 **＋ Add to path** 加入。」
- **All assigned courses**：「這個計畫底下所有課程的總清單。」
- **Move program**：「可以把課程**轉移到另一個我管理的計畫**，教材、報名資料與學習進度都會保留；但審核中的課程要先撤回。」
- **＋ Create a course in this program / Add existing course**：「也能直接在計畫中建立新課程或加入既有課程。」

---

## 3. Instructors 講師指派（約 45 秒）

【畫面操作】點選側邊欄 **Instructors**（Assignments 頁）。

「這一頁讓我決定**每一門課由哪位講師負責**。」
- 【操作】用搜尋框搜尋課程或講師。
- 【操作】選一門課 → **Assign instructor** → 選講師 → **Save assignment**。
- 「這樣可確保每門課都連結到對的講師，講師就能開始編輯內容。」

---

## 4. Course approvals 課程審核（約 2 分鐘，重點功能）

【畫面操作】點選側邊欄 **Course approvals**。

「講師提交課程後，不會直接上線，要由 Program Leader 審核。這就是**品質把關**的核心。」

### 4.1 Requests 申請看板
- 「這裡集中所有**建立／更新**與**刪除課程**的申請，可以用 **Board 看板** 或 **Table 表格** 兩種視圖切換。」
  【點擊】Board ↔ Table。
- **日期列**：「用日期列看某天提交的申請，左右箭頭可以前後翻 12 天，**All dates** 取消日期篩選。」
- **篩選**：「搜尋課程／講師／申請內容；依**申請類型**（Create/update、Delete）與**所屬計畫**過濾。右上角會顯示符合的申請數量。」

### 4.2 審核單筆申請
【點擊】開啟一筆申請。
- 「頁面會顯示**申請內容、課程現況，以及申請進度時間軸**。」
- 【點擊】**Start review** 開始審核。
- 右側 **Your decision**：
  - 一般課程可選 **Approve（核准並發佈）／Reject（退回）／Request changes（要求修改）**。
  - 刪除申請則是 **核准＝刪除課程，駁回＝保留課程**。
  - 「**Feedback 為必填**，意見會直接回傳給講師。」
  【操作】選 Request changes → 填 feedback → **Submit decision**。
- 「決定送出後，申請變成唯讀，並寫進時間軸，留下完整紀錄。」
- 「若這筆申請不屬於我的計畫，系統會顯示 **Request access denied**，不能越權。」

---

## 5. Program analytics 學習分析（約 1 分鐘）

【畫面操作】從 Dashboard 的「Program analytics」進入 **Analytics**。

「這頁是**數據分析**。」
- 上方統計卡：整體數字。
- **Programs 表**：每個計畫的課程數、報名數、完成率、測驗平均分。
- **Courses 表**：每門課的報名、**參與度**、完成率、測驗平均分。
- 【點擊】**All / Active / No enrolments** 篩選，找出沒人報名的課。
- 【點擊】**Load More** 載入更多。
- 【點擊】**↓ Export CSV** 匯出報表，**Print** 列印。
- 「數據來自實際的報名與測驗紀錄，參與度＝至少完成一個活動的報名數。」

---

## 6. Learners 學習者追蹤（約 30 秒）

【畫面操作】Analytics 右上 **Learners**。

「這裡是**學習者表格**：學習者、課程、進度、狀態、最後活躍時間。」
- 【點擊】**View** 查看單一學習者的完整學習紀錄。
- 「必要時也能 **Remove** 移除報名（系統會先跳出確認提示）。」

---

## 7. Messages 訊息（約 20 秒）

【畫面操作】點選 **Messages**。

「Program Leader 可以和講師、學習者**私訊**，也能使用課程頻道與公告。例如審核時想進一步溝通，直接傳訊給講師就可以。」

---

## 8. 結語（約 20 秒）

「總結一下，Program Leader 的五大能力：

1. **Overview**：一眼掌握計畫狀況與待辦通知
2. **Programs**：建立計畫、安排課程學習路徑
3. **Instructors**：指派每門課的講師
4. **Course approvals**：審核課程的建立與刪除申請，並回饋意見
5. **Analytics / Learners**：用數據追蹤成效與學習者進度

這讓每一門上線的課程，都有人負責、有人把關、有數據可以檢視。謝謝大家。」
