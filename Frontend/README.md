# Skill UP frontend

Notes for working on the frontend. For setup, demo accounts and the overall project layout, see the [root README](../README.md). For backend integration, see [docs/BACKEND-HANDOFF.md](../docs/BACKEND-HANDOFF.md) and [docs/API-CONTRACT.md](../docs/API-CONTRACT.md).

## Layout

| Path | Contents |
|---|---|
| `*.aspx` + `*.aspx.cs` | Web Forms entry pages. Each `Page_Load` sets the initial hash route. The full list is in [docs/WEBFORMS-PAGES.md](../docs/WEBFORMS-PAGES.md). |
| `SkillUp.Master` | Shared master page. It loads every stylesheet and script in the same order as `index.html`. |
| `index.html` | Standalone entry used by `server.cjs` and the browser tests |
| `css/` | Stylesheets. Later files override earlier ones. |
| `js/app.js`, `js/pages.js` | Router, permission gates, shared rendering helpers |
| `js/api.js`, `js/runtime-config.js` | `SkillAPI.request(...)`, the only data boundary (mock or HTTP) |
| `js/seed.js`, `js/*-data.js` | Mock data fixtures. Not for production. |
| `js/<feature>.js`, `js/<feature>-art.js` | One module per screen. The `-art` files hold that screen's decorative Figma artwork layers as HTML, generated by `scripts/build-*-art.cjs` |
| `assets/` | Images, icons and fonts used at runtime |
| `design/` | Figma exports and reference images, used only by `scripts/build-*.cjs` |
| `scripts/` | `check-handoff.cjs` (static check), `test-domain.cjs` (domain test runner), `build-*`, `preview-*` and `capture-*` design tools |
| `tests/` | `*-data.cjs` and `domain.cjs` run in Node; the rest are Playwright browser tests |

[docs/MODULE-MAP.md](../docs/MODULE-MAP.md) shows which files own each feature.

## Common tasks

- **Add a stylesheet:** put it in `css/`, then add the same `<link rel="stylesheet" href="css/….css">` at the same position in `index.html` and `SkillUp.Master`. Asset URLs inside it start with `../assets/`. Update [docs/LOAD-ORDER.json](../docs/LOAD-ORDER.json) as well.
- **Add a script:** put it in `js/` and add the `<script>` tag to both entry files. Keep `js/app.js` last.
- **Add a page:** create `Name.aspx` and `Name.aspx.cs` like the existing pairs, add a `Compile` item to `SKILL UP.csproj`, and add an entry to `docs/WEBFORMS-PAGES.json` (the static check reads it).
- **Switch to the real API:** set `mode: 'http'` in `js/runtime-config.js`. By default, `baseUrl` points to `/api` one level above `Frontend/`.

After any of these, run `npm test` from this folder.

## Notes

- Data is stored in `localStorage` for each origin, so IIS Express, `node server.cjs` and `file://` each have their own copy.
- Camera preview needs `localhost` or HTTPS.
- The Test video call / Receive call buttons in the navbar are temporary previews. Turn them off with `SHOW_INCOMING_CALL_TEST` in `js/workspace-nav.js` before release.
- `tests/handoff-ui.cjs` is the maintained browser check. Some other UI tests target earlier designs.
