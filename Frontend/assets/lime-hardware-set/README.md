# Skill UP — Lime hardware collection

Six separate computer hardware illustrations generated with the built-in image generation tool: memory card, PC tower, retro computer, server, SSD and router.

Art direction: fluorescent lime transparent polycarbonate, visible dark circuit boards, gold contacts, graphite accents, glossy bevels, three-quarter isometric product view. Requested transparent background and generous margins for use as individual learning-path assets.

The full generation prompts are saved in prompts.json.
